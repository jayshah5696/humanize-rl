Humanize-RL

System Architecture & Gating Verification Pipeline

Transformation Workflow STAGE_RUNNER

INPUT

1. Human Seeds

Raw human seed prompts (8,000 samples) streamed dynamically across 5 domains (Academic, Blog, Creative, Email, Instruction).
  • Original text distribution
  • No AI writes/tells
  • Diverse instruction tasks
DISTORTION

2. AIify Stage

Model: gemini-3.1-flash-lite. Prompts are distorted to inject distinct AI fingerprints (sycophancy, list overuses, structural symmetries).
  • Baseline AIified text
  • Establishes lower anchor
  • Generates 6,897 candidates
ALIGNMENT

3. Humanize Stage

Model: gemini-3-flash. Paraphrases the AIified inputs to completely strip synthetic markers while matching the tone register.
  • Refinement rewrite
  • Enforces facts preservation
  • Inputs to Gating Stage

Multi-Layer Filtering Gate VERIFIER_GATE

Layer 1 Stylometric Gate (Deterministic)
Sentence Variance
S_variance
Checks coefficient of sentence length variation. Rejects flat pacing.
List Overuse
S_list
Measures bullet ratio. Rejects markdown list structures.
Hedging Density
S_hedge
Scans for defensive phrases (e.g., "worth noting").
Opener Pattern
S_opener
Filters conversational chatbot greetings ("Certainly!").
Contraction Rate
S_contract
Monitors presence of contractions in informal text.
Closing Pattern
S_closer
Rejects conversational disclaimers ("I hope this helps").
Em-Dash Density
S_dash
Identifies synthetic cadence via overuse of dashes.
Transition Overuse
S_transition
Scans for formal transitional padding ("Moreover").
Semantic Preservation Gate
CI

Case-Insensitive Entity Matching

Extracts sequence proper nouns from seed text and verifies complete presence in rewrite, ignoring capitalization changes (e.g. "github" vs "GitHub").

PN

Proportional Number Gating

Enforces strict 100% number matches for short texts (≤5 numbers). Allows up to 15% drop rate tolerance for long technical tables to avoid false rejects.

ES

Email System Header Stripping

Filters out metadata headings (e.g., "From:", "Subject:") prior to running entity verification to prevent false format mismatch flags.
